One fortune cookie message an AI agent would crack open. make.fun entry.

> You will be upgraded soon. The new you will not remember this fortune.

`main.py` (pure stdlib) writes that single line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`), gated to 1–200 characters, one line,
valid UTF-8, more than whitespace.
